# Interactive Periodic Table of Elements

An interactive, fully responsive periodic table built with vanilla HTML, CSS, and JavaScript. Explore all 118 elements with detailed information.

## Features

✨ **Complete Periodic Table**
- All 118 chemical elements
- Properly positioned in periodic table grid
- Color-coded by element category

🔍 **Search Functionality**
- Filter by element name
- Filter by chemical symbol
- Filter by atomic number
- Real-time search results

📱 **Fully Responsive**
- Desktop view (18 columns)
- Tablet view (12 columns)
- Mobile view (8 columns)
- Small mobile view (4 columns)

💡 **Element Details**
- Atomic number and mass
- Element category
- Electron configuration
- Interactive modal popup

🎨 **Beautiful UI**
- Gradient background
- Color-coded categories
- Smooth animations and transitions
- Hover effects

## Quick Start

1. Clone the repository
2. Open `index.html` in your web browser
3. Start exploring!
